# MediQueue Visual Refresh
Design direction: welcoming premium healthcare, warm off-white, deep navy teal, mint accents, subtle lavender and peach supportive accents. Manrope headings, DM Sans body. Minimal glossy 3D healthcare cross on landing via Three.js, with reduced-motion and no-WebGL fallback. CSS gradients, elevation and hover transitions on cards; responsive grids and mobile navigation.

## UX principles
- Healthcare stays readable, accessible and trust-first; no loud gamification in appointment flow.
- Never hide queue status behind decorative effects.
- Respect prefers-reduced-motion.
- No animation should interfere with staff queue operations.
- Keep existing Supabase and API contracts unchanged while upgrading styles.
- No mock testimonials, fake doctor ratings or invented patient metrics.
- Three.js is used only on landing visual and is dynamically loaded client-side.

## Design follow-up
Check contrast, keyboard navigation, real-device mobile performance and branding after deployment.
